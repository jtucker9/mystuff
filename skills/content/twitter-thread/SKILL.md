## Instructions

### Step 1: Gather Inputs

Collect before writing — no defaults for topic or audience:

- **Topic** and **key insight** (the single takeaway)
- **Target audience** (who should care)
- **CTA** (follow / reply / visit link / sign up)
- **Tone** (educational, provocative, storytelling, data-driven, personal)
- **Thread length** — decision rule:
  - Short (5-7): single concept, quick wins, tool lists
  - Medium (8-10): framework or how-to with evidence
  - Long (11-15): deep story, contrarian argument with multiple data points

**Gate:** All six inputs confirmed before proceeding.

### Step 2: Select Thread Structure

Pick structure based on topic + tone alignment:

| Type | Pattern | Select When |
|------|---------|-------------|
| **Story** | Hook > Setup > Conflict > Resolution > Lesson > CTA | Personal experience, transformation narrative |
| **Framework** | Hook > Context > Principle 1-3 (each with evidence) > Synthesis > CTA | Mental models, strategic thinking |
| **Listicle** | Hook > Item 1 > Item 2 > ... > Summary > CTA | Tools, tips, resources, curated lists |
| **Contrarian** | Hook > Common belief > Why it's wrong > Real truth (with data) > Implication > CTA | Hot takes, myth-busting, industry critique |
| **Case study** | Hook > Background > Problem > Approach > Results (with numbers) > Lesson > CTA | Company analysis, personal results |

**Gate:** Structure type selected and arc sketched before writing tweets.

### Step 3: Write the Hook Tweet

The hook determines whether anyone reads the rest. Apply these rules strictly:

- Must work as a standalone tweet — never "Thread" or thread emoji
- First 50 characters matter most (timeline preview cutoff)
- No hashtags in hook
- End with colon or open loop implying more
- Never start with "I" — lead with the insight
- 280 char max, aim for under 200

**Hook formula selection** — match to structure type:
- Story/Case study: story opener ("Last year I was broke. This year...")
- Framework: bold claim or question ("Why do some people learn in 6 months...")
- Listicle: list promise with specificity ("10 tools that replaced my $500/mo stack")
- Contrarian: controversial statement or surprising stat ("97% of SaaS startups fail. The 3% all do this:")

**Gate:** Hook tweet passes standalone-value test and is under 280 chars.

### Step 4: Write Body Tweets

Per-tweet rules:
- 280 char max. One idea per tweet. Each must deliver value standalone.
- Short lines (2-5 words) for mobile readability. Use line breaks between ideas.
- Tweets 2-8: end with implied continuation to pull readers forward.
- Include 2-3 data points across the thread (stats, case studies, personal numbers, before/after, comparisons).
- Use specificity over vagueness: "$10,847 in revenue" not "lots of money."

**Formatting tools:** bullets for lists, arrows for steps, nested arrows for sub-points. Use numbers ("3 reasons", "saved $50K", "in 14 days") and contrast ("Most people X. Top performers Y.").

**Avoid:** "Also,", "Additionally,", tweet numbering (1/10), thread emoji, more than two questions in a thread, hashtags mid-thread, filler words (basically, actually, just), passive voice.

**Gate:** Each tweet passes 280-char check and one-idea rule.

### Step 5: Write CTA Tweet

Final tweet must summarize + prompt one clear action. Choose CTA format:

- **Follow CTA**: TL;DR bullets + "Follow @handle for more [topic]"
- **Link CTA**: Tease the resource + link. State what it contains (pages, templates).
- **Engagement CTA**: "Which resonated most? Reply with the number" + numbered options
- **RT CTA**: "RT the first tweet to help others find it" + follow prompt

Only one CTA per thread. Never stack multiple asks.

**Gate:** CTA has exactly one action and matches the user's specified CTA type.

### Step 6: Output and Engagement Strategy

Present as paste-ready numbered thread with metadata header. Include posting notes:

- **Self-reply timing**: Post all tweets within 2-3 minutes (use scheduling tool or paste rapidly). Gaps kill thread visibility.
- **Quote tweet strategy**: Quote-tweet the hook with a one-line teaser 24 hours later for second wave.
- **Engagement window**: Reply to every comment in first 2 hours. Like all quote tweets. This signals the algorithm.
- **Repost**: Thread again in 30 days with updated data or new hook angle.
- **Best posting times**: Weekdays 8-10am or 12-1pm in audience timezone.
- **Pin**: Pin the thread to profile after posting.

## Examples

**Example 1 — Framework thread (medium, educational)**
Topic: "Why most to-do lists fail." 8 tweets. Hook: bold claim challenging common practice. Body: 3 principles with one evidence tweet each. CTA: follow for productivity content.

**Example 2 — Listicle thread (short, data-driven)**
Topic: "Free tools replacing paid SaaS." 6 tweets. Hook: list promise with dollar amount saved. Body: one tool per tweet with specific use case. CTA: RT first tweet + follow.

## Common Issues

| Problem | Fix |
|---------|-----|
| Thread feels like blog post chopped into tweets | Rewrite — each tweet needs its own tension or payoff, not a continuation sentence |
| Hook gets no engagement | Test: would you click if you saw only the first 50 chars? If not, rewrite with stronger open loop |
| Thread too long, drops off after tweet 5 | Cut evidence tweets, merge points. If over 10, every tweet must earn its slot |

## Anti-Patterns

- Writing the thread as a single essay then splitting by character count
- Leading with credentials instead of insight ("As a 10-year veteran...")
- Stacking multiple CTAs in the final tweet
- Using thread emoji or "Thread:" prefix — signals low quality
- Hashtag stuffing anywhere in the thread

## Escalation

- If topic requires nuance beyond 15 tweets: suggest blog post (blog-post skill) + thread as teaser
- If user wants to repurpose thread to other platforms: hand off to content-pipeline skill
- If topic is time-sensitive news: prioritize speed over polish, skip evidence gathering
