# TikTok Script — Short-Form Video Script Builder

## Activation

| Context | Status |
|---------|--------|
| User says "TikTok script", "Reels script", "Shorts script" | ACTIVE |
| User wants a short-form video script (15-90 seconds) | ACTIVE |
| User asks about hooks, pattern interrupts, viral video strategy | ACTIVE |
| User wants written content (thread, newsletter, blog) | DORMANT |
| User wants long-form video (webinar, full YouTube) | DORMANT |

Output: `TikTok Script — Writing your short-form video script...`

## Instructions

### Step 1: Gather Inputs

Collect before writing. If any are missing, ask:

- **Topic** — what the video teaches, shows, or argues
- **Hook angle** — the scroll-stopping promise or provocation
- **Audience** — who this targets (niche, experience level)
- **Duration** — 15s, 30s, 60s, or 90s
- **Format** — talking head / POV / green screen / stitch / duet / text overlay / screen recording
- **CTA** — follow, comment, save, share, or link in bio
- **Platform priority** — TikTok, Reels, or Shorts (affects caption length and audio)

Gate: All 7 inputs confirmed before proceeding.

### Step 2: Write the Hook (First 1-3 Seconds)

The hook determines 95% of performance. Viewer decides stay-or-swipe in under 2 seconds.

**Hook type selection:**

| Type | When to use |
|------|-------------|
| Pattern interrupt | Visual surprise + unexpected claim — entertainment, product |
| Bold statement | Contrarian take — opinion, education |
| Direct question | Triggers need-to-know — how-to, health, money |
| Audience filter | "If you're a [role], watch this" — niche targeting |
| Result tease | Transformation promise — before/after, growth |
| POV | Viewer self-insert — relatable, lifestyle |
| Controversy | Emotional trigger — debate, hot takes |

**Hook rules:**
- First spoken word within 0.5 seconds. No "Hey guys" warmups.
- Visual movement or change in frame one.
- Text overlay reinforcing the hook — assume sound-off viewers.
- Never open with logo, name, or intro sequence.

Gate: Hook is one sentence, under 10 words, passes the "would I stop scrolling?" test.

### Step 3: Write the Body

Pacing by duration — every second must earn its place:

**15s:** Hook (0-2s) > One point delivered fast (2-10s) > CTA (10-15s). No setup, no context. Pure value.

**30s:** Hook (0-2s) > Setup/why it matters (2-8s) > Main content, max 3 sub-points (8-22s) > Payoff (22-28s) > CTA (28-30s).

**60s:** Hook (0-2s) > Context + audience filter (2-8s) > Point 1 (8-18s) > Point 2 (18-28s) > Point 3 (28-40s) > Key takeaway (40-50s) > Proof/stat (50-55s) > CTA (55-60s).

**90s:** Same as 60s structure but expand points to include mini-examples. Add a second hook or re-hook at the 30s mark to retain viewers past the drop-off cliff.

**Pacing rules:**
- One video = one clear idea. Never try to teach everything.
- TikTok speech pace: 160-180 wpm (faster than conversational).
- 8th-grade vocabulary. Simple words, short sentences.
- Show > tell. Screen recording, whiteboard, hands-on demo.
- Zero dead air. Cut every pause that doesn't build tension.

Gate: Script word count fits duration (40 words/15s, 80/30s, 160/60s, 230/90s approximate).

### Step 4: Annotate Visual and Audio Cues

Each timestamp includes: spoken line, visual direction, text overlay (critical for sound-off), and sound/music cue.

**Format drives annotation style:**

| Format | Key annotations |
|--------|----------------|
| Talking head | Camera angle, expression, gesture, B-roll cuts |
| POV | Camera position, hands-in-frame action, environment |
| Green screen | Background image/video source, pointing gestures |
| Stitch/Duet | Original video pause points, reaction timing |
| Text overlay | Font style, animation timing, reveal sequence |
| Screen recording | Cursor movement, highlight zones, zoom timing |

### Step 5: Audio and Trending Strategy

**Decision tree:**

- Educational/tutorial content > original voice, clear and confident
- Entertainment/lifestyle > trending sound, adapt or lip-sync
- Demo/screen recording > voiceover + lo-fi or trending beat underneath
- Story/confession/tips list > text-only + emotional or trending music

**Trending audio rules:**
- Check platform's trending page before recommending specific sounds.
- Original audio builds your brand; trending audio borrows reach.
- If the hook is spoken, original audio is usually stronger.
- Trending sounds have a 3-7 day peak window — publish fast or skip.

### Step 6: Caption and Hashtag Optimization

**Caption structure:** Hook line (matches video energy) > 1-2 sentences of value/context > CTA.

**Platform-specific limits:**
- TikTok/Reels: 2,200 chars (only first 1-2 lines visible before "more")
- Shorts: 100 chars (keep extremely tight)

**Hashtag allocation:** 3-5 broad reach (#fyp, #learnontiktok) + 5-8 niche-specific + 3-5 topic-specific + 2-3 trending. Total: 15-20 for TikTok/Reels, 3-5 for Shorts.

### Step 7: Deliver Script Package

Output format — all sections required:

1. **Header:** Topic, duration, format, target audience
2. **Timestamped script:** Every beat with spoken line + visual + text overlay + audio cues
3. **Caption:** Full text with hashtags, platform-adapted
4. **Audio recommendation:** Original vs trending, specific style suggestion
5. **Cross-platform notes:** Adaptation differences for TikTok/Reels/Shorts (audio library, hashtag count, CTA wording, stagger posting: TikTok Day 1 > Reels Day 2 > Shorts Day 3)

Gate: Script has a hook under 2 seconds, visual cues on every beat, and a single clear CTA.

## Examples

**Example 1 — 30s talking head, dev niche:**
Topic: "Stop using console.log for debugging." Hook type: bold statement. Format: talking head + screen recording cut. Audio: original voice. CTA: follow. Caption leads with hook, 18 hashtags mixing #codingtok + #javascript + #devtips. Stagger: TikTok first, Reels next day with Reels-trending audio swap.

**Example 2 — 15s text overlay, business niche:**
Topic: "3 signs your pricing is too low." Hook type: direct question. Format: text overlay + trending audio. Audio: trending sound, no voiceover. CTA: save + comment. Caption: 2 lines max visible, 15 hashtags. Shorts adaptation: cut to 100-char caption, 4 hashtags only.

## Common Issues

- **Hook too slow:** If the first spoken word is after 1 second, the hook is failing. Restructure to lead with the most provocative word.
- **Too many points:** Short-form rewards depth on ONE idea, not breadth on five. If the script has more than 3 sub-points in 60s, cut to the strongest.
- **Sound-off neglected:** 40-50% of viewers watch without sound. If the video doesn't work with text overlays alone, add them to every beat.

## Anti-Patterns

- Writing a mini-essay instead of a spoken script (written cadence != spoken cadence)
- Starting with "Hey guys" or any throat-clearing before the hook
- Using the same CTA for every platform (Shorts needs "Subscribe", not "Link in bio")
- Cramming 60s of content into a 15s duration — match depth to length
- Ignoring trending audio windows — a trending sound from 2 weeks ago is dead
