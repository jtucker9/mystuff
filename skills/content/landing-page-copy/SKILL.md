# Landing Page Copy

## Activation

| Context | Status |
|---------|--------|
| "landing page", "sales page", "conversion copy", "hero section" | ACTIVE |
| Waitlist, signup, lead gen, or free trial page copy | ACTIVE |
| Blog content, email campaigns, ad copy, product descriptions | DORMANT -- wrong skill |

Output on activation: `Landing Page Copy -- Crafting your conversion copy...`

## Inputs

**Required:** Product/service, target audience (role + psychographics), primary CTA (single action), unique value proposition (one differentiator).

**Optional:** Page type (Sales/Lead gen/Waitlist/Signup/Free trial/Webinar/Demo), price point, traffic source (determines awareness calibration), tone (default: confident, conversational), existing assets (testimonials/case studies/logos), competitor URLs.

## Instructions

### Step 1: Customer Research Synthesis

Build before writing anything. Four deliverables:

**Voice of Customer** -- Mine support tickets, competitor reviews (G2/Capterra), Reddit/HN, sales calls, surveys for 10-20 phrases in the customer's actual language, organized by theme.

**Pain Hierarchy** -- Rank pain across four levels:
- L1 Surface (daily symptoms) -- use in hero
- L2 Operational (business cost with numbers) -- use in problem section
- L3 Strategic (6-12 month trajectory if unsolved) -- use in solution section
- L4 Identity (how it makes them feel) -- use in closing CTA

**Desire Mapping** -- Mirror pain hierarchy: functional desire (features satisfy), emotional desire (benefits satisfy), identity desire (transformation satisfies). Strong pages hit all three.

**Objection Inventory** -- Rank every reason the prospect won't convert. Each objection maps to a specific page section: FAQ, social proof, feature descriptions, or guarantee.

**Gate:** Do not proceed to Step 2 until all four deliverables exist.

### Step 2: Awareness Level Calibration

Assess using Schwartz's 5 levels. This determines page length, hero strategy, and section weight.

| Level | Hero Strategy | Page Calibration |
|-------|--------------|-----------------|
| Unaware | Lead with problem, educate first | Long page, heavy problem section |
| Problem-Aware | Agitate pain, introduce category | Long page, bridge pain to solution |
| Solution-Aware | Name category + your advantage | Medium page, differentiation focus |
| Product-Aware | Overcome objections, prove value | Shorter page, proof-heavy |
| Most Aware | Lead with offer, remove friction | Short page, CTA-forward |

Traffic source heuristic: content/social = Unaware, SEO/educational ads = Problem-Aware, comparison searches = Solution-Aware, retargeting/email = Product-Aware, brand search/referrals = Most Aware.

**Gate:** Awareness level must be declared before hero writing.

### Step 3: Hero Section

Must pass the grunt test: what is this, why should I care, what do I do next -- in 5 seconds.

**10 headline formulas** (select by awareness level):

| # | Formula | Best Awareness |
|---|---------|---------------|
| 1 | [Verb] [Outcome] Without [Pain] | Product-Aware |
| 2 | The [Category] That [Differentiator] | Solution-Aware |
| 3 | [Outcome] in [Timeframe] | Product-Aware |
| 4 | Stop [Pain]. Start [Desire]. | Problem-Aware |
| 5 | [Number]+ [Group] [Verb] [Product] to [Outcome] | Product-Aware |
| 6 | What If [Desired Scenario]? | Unaware |
| 7 | [Audience]: [Direct Benefit] | Problem-Aware |
| 8 | The Fastest Way to [Outcome] | Problem-Aware |
| 9 | [Bold Claim]. [Proof Fragment]. | Solution-Aware |
| 10 | [Do X]. [Without Y]. [In Z]. | Product-Aware |

**Hero CTA by page type:**

| Page Type | Button Text Pattern | Below-Button |
|-----------|-------------------|-------------|
| Free trial | "Start Free Trial" / "Try Free for N Days" | No credit card + setup time |
| Sales | "Get Started" / "Buy Now" | Money-back guarantee |
| Lead gen | "Get the [Resource]" | Social proof count |
| Waitlist | "Join the Waitlist" | Queue position |
| Signup | "Create Free Account" | Free tier scope |
| Webinar | "Save My Spot" | Date + replay note |
| Demo | "Book a Demo" | Duration + no pressure |

CTA rules: first person outperforms second person, always start with verb, below-button text reduces anxiety, never use "Submit."

**Gate:** Hero must pass -- (1) grunt test, (2) single CTA, (3) at least one concrete number, (4) headline under 10 words for mobile.

### Step 4: Problem / Agitation

Three escalating layers drawn from Step 1 pain hierarchy:

1. **Symptom** -- Name daily frustrations in VoC language
2. **Cost** -- Translate to measurable business impact with specific numbers
3. **Trajectory** -- Project forward 6-12 months if nothing changes

Agitate through honesty, not manufactured fear. Use real statistics, acknowledge alternatives exist, name cost of inaction with math. Frame the status quo as the true competitor, not rival products.

**Gate:** Problem section must be 150-300 words minimum. If shorter, it's not earning the right to present a solution.

### Step 5: Solution and Features

Bridge sentence connects pain to product. Then apply the "So What?" test to every feature:

State the feature -> ask "So what?" -> ask again -> final benefit the buyer values. Lead copy with the benefit, mention feature as mechanism.

Present 3-4 benefit clusters in parallel structure (headline + 2-3 sentences + proof point each). Each block independently scannable.

For non-obvious workflows, add a 3-step "How It Works" (always exactly 3 steps, each starts with verb).

### Step 6: Social Proof

Distribute across the page, not in one cluster. Placement map: Hero (logo bar, user count, rating -- 2-3 max), After problem (pain-validation testimonial), After features (outcome testimonial, case study snippet), Before pricing (objection-killer testimonial, security badges), Final CTA (guarantee, awards, aggregate score).

**Testimonial types:** Before-After-Bridge, Specific Outcome, Objection-Killer, Identity. Each must include specifics -- no "Great product!" testimonials. Min 3, max 6 per page, each addressing a different benefit or objection.

### Step 7: Objection Handling and Pricing

FAQ = objection handling in disguise. Frame questions in prospect's voice, not marketing voice. 6-10 entries, ordered by objection frequency. Each answer: direct response first, then elaboration.

Match guarantee to price point: free trial needs none, under $100/mo gets money-back, $100-500/mo gets results guarantee, $500+ gets ROI guarantee, enterprise gets pilot program.

**Pricing presentation anchor technique** (when price is shown):
1. Recap value received
2. Anchor against status quo cost (the alternative's price)
3. Present your price
4. Restate in accessible terms (per day, per user)
5. Add guarantee

Formula: "[Alternative cost] vs [your price] = [savings] per [period]."

**Urgency ethics:**

| Legitimate | Never use |
|-----------|-----------|
| Time-limited pricing with real deadline | "Only X left" on digital products |
| Capacity constraints (real onboarding limits) | Countdown timers that reset |
| Cohort-based enrollment | "This offer won't last" on evergreen pages |
| Time-to-results framing | Any scarcity claim that's false |

### Step 8: Final CTA and Output

Final CTA is more assertive than hero CTA (reader has more context now).

**CTA copy formulas:** Action+Outcome, Imperative+Timeframe, Value Stack Recap, Social Proof+Action, Question+Answer, Identity+Action.

Include a value stack recap (bullet list of everything they get), then a 2-3 sentence paragraph for the reader who scrolled everything but hasn't clicked -- speak directly to their hesitation.

Deliver as structured copy document with sections: Research Foundation, Hero, Problem/Agitation, Solution/Features, Social Proof, Objection Handling, Pricing (if applicable), Final CTA, Wireframe Notes, Page Metadata (title, meta description, OG tags).

## Examples

**High-ticket SaaS, Solution-Aware traffic:**
Research -> Pain hierarchy with $127K/yr status quo cost -> Headline formula #2 (category + differentiator) -> Medium-length page -> Comparison table in objection handling -> ROI guarantee -> Anchor pricing against engineering time cost.

**Waitlist page, Unaware audience:**
Research -> Heavy VoC mining -> Headline formula #6 (What If?) -> Long page with extended problem section -> No pricing -> Social proof via early adopter count -> CTA: "Get Early Access" with queue position below button.

## Common Issues

**Generic copy that sounds like every competitor** -- Step 1 was skipped or shallow. Go back and mine 10-20 VoC phrases before rewriting.

**Hero fails grunt test** -- Too clever, too abstract, or uses internal jargon. Rewrite headline under 10 words using formula matched to assessed awareness level.

**Page converts poorly despite good copy** -- Awareness level mismatch with traffic source. Verify Step 2 calibration matches where visitors actually come from.

## Anti-Patterns

- Writing copy before completing customer research synthesis
- Feature-first hero (features explain how; hero must explain why)
- Multiple competing CTAs in hero section (one primary per section)
- Problem section under 150 words (hasn't earned the right to present solution)
- Manufactured urgency (countdown timers on evergreen, fake scarcity on digital)
- Testimonials without specifics (no measurable outcome = zero persuasive value)
- Identical hero and final CTA (final must be more assertive with value stack)
- Skipping awareness level assessment (page-traffic mismatch kills conversion)

## Escalation

- Custom design/interactives -- produces copy and wireframe notes, not visual designs
- A/B testing -- produces one optimized variant; structured experimentation needs CRO specialist
- Regulated claims (health, financial, legal) -- require compliance review before publication
- Multi-page funnel -- map full funnel with sales-funnel skill first

## Outputs

Structured copy document: research foundation, hero (headline + subheadline + CTA + badges), problem/agitation (150-300 words), solution/features (3-4 benefit blocks + how-it-works), social proof (3-6 testimonials + case study + numbers bar), objection handling (6-10 FAQs + guarantee + comparison table if applicable), pricing (if applicable), final CTA (value stack + hesitant reader paragraph), wireframe notes, page metadata (title, meta description, OG tags).
